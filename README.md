## 快速添加

- 成员：点击网站上的「提交收录」填写 Issue，审核通过后会自动收录。已存在 GitHub 用户名会更新资料；博客留空不会删除已有博客。

- 项目：点击项目页的「提交项目」填写 Issue，或修改 `data/projects.json` 提交 PR。同一项目链接会更新资料。

- 本地检查和同步：

```bash
npm --prefix frontend run validate:data
npm --prefix frontend run generate:readme
npm --prefix frontend run collect:posts # 只在新增/修改博客时需要
```
